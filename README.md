# P2_Micro_Blogging (Group 25)
This project is meant to simulate a web-blogging application, where users can interact with each other and make posts. The purpose of this project is to build and manage a large database for a full-stack application, and understand how it is meant to be used. The original project structure is provided by Prof. Sami Menik at the University of Georgia.
